# Roadmap

## 0.1 — Orientation
- portable math types
- pose model
- sensor abstraction
- local 3DoF orientation
- stereo camera/render loop
- frame timing diagnostics

## 0.2 — Camera
- native camera adapter
- passthrough experiment
- calibration model

## 0.3 — Positional tracking research
- feature tracking
- IMU/camera timestamp synchronization
- visual-inertial odometry prototype
- drift/error diagnostics

## 0.4 — Spatial runtime
- 6DoF pose
- anchors/map representation
- persistence as an optional local subsystem

## Later
- hand/input abstraction
- dedicated hardware adapters
- custom Linux/embedded target exploration

Milestones are capability gates, not promises of headset-grade tracking.
